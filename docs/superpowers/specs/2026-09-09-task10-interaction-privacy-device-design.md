# Task 10：小程序交互、隐私与真机质量设计

日期：2026-09-09。状态：用户已确认设计方向，等待审阅规格后进入实施计划。所有开发、测试和启动只在主目录进行。

## 目标与边界

Task 10 将 Task 1–9 整理为可持续使用的小程序体验：补齐设置、关于、隐私入口，建立明确导航和统一错误恢复，保持已有登录、成员、邀请、分类、账户、记账和统计接口语义不变，并为 Mate 70 Pro 与 iPhone 15 真机验收提供检查清单。

本任务不实现生产发布、不修改服务器公网监听、不清理数据库、不改变 AppSecret、数据库密码、APP_BOOTSTRAP_KEY 或 Pepper，不引入支付、图片/OCR、导出、预算、多账本或第三方 UI 框架。正式域名未备案前只预留配置，不把 117.72.101.42:7631 标记为体验版或正式版可用地址。

## 导航与页面

采用微信原生四栏底部导航：首页、明细、统计、我的，分别映射 pages/home/index、pages/entry-list/index、pages/statistics/index、pages/settings/index。现有 pages/profile/index 继续作为资料编辑子页，不把资料表单改成 tab 根页。“记一笔”不作为第五个 tab，保留首页和明细页的主操作入口。登录、初始化、邀请加入和无权限状态不放入 tabBar；失去会话统一回到登录页，保留现有会话恢复和 401 处理。登录页可在没有有效后端配置/会话时阅读关于和隐私，不能因阅读说明触发额外登录或被过期回调跳走。

新增 pages/settings/index、pages/about/index、pages/privacy/index。设置页提供版本、关于/隐私入口和退出登录，不修改服务器密钥或数据库配置。关于页提供应用名称、版本、运营方/联系方式、备案号和工信部查询入口；空配置显示“待配置/备案中”，不得编造备案信息。隐私页说明微信身份标识、昵称/头像、会话令牌、共享账本账单、审计和邀请数据的用途、范围、保留/退出行为，并说明邀请码复制只在用户点击后执行。

## 交互状态与隐私边界

所有数据页区分 loading、空数据、无权限、网络失败和服务端错误。网络失败显示请求编号和重试按钮，保留表单输入；提交按钮请求期间禁用。客户端不得对未知结果的写请求自动重试，账单创建继续使用 clientRequestId 幂等，更新/删除继续使用 version 乐观锁。

统一处理邀请失效、账本已满、成员权限不足、会话过期、编辑冲突、分类/账户停用关联以及服务端 4xx/5xx；错误不能渲染为零数据或空成功页面。过期请求不得覆盖当前页面状态。

只使用现有登录、昵称输入、头像展示、用户主动点击后的邀请码复制/分享和网络请求。不新增位置、相册、摄像头、麦克风、手机号、剪贴板读取或通讯录权限。隐私页面必须与最终静态代码调用清单一致，新增需平台授权的接口前重新核对官方指引。

## API 地址与临时域名

account-book-miniapp/miniprogram/config/env.ts 是唯一 API 地址解析入口。develop 继续使用 http://127.0.0.1:7631；trial 使用单独临时 HTTPS 域名；release 使用单独正式 HTTPS 域名。体验/正式地址缺失、不是 HTTPS、包含 IP/localhost 或格式不安全时，在发起请求前返回配置错误，不回退到开发库或公网 IP。

临时域名只作集中配置占位。服务器预期链路为 HTTPS:443 → Nginx → 127.0.0.1:7631；后端仍只监听回环地址，数据库端口和 7631 不开放公网。DNS、备案、受信任证书和微信 request 合法域名是后续 Task 11/12 门禁。

登录会话必须绑定构建环境和规范化 API origin；不同环境或主机的令牌不得交叉恢复或发送。旧缓存缺少环境标识时清除并重新微信登录，不猜测令牌所属环境、不搬运凭据。实际域名/证书校验和备案状态不是字符串格式校验所能证明，代码提示不得误称已备案。

## 真机验收

在 Mate 70 Pro 和 iPhone 15 各登记系统名称/版本、微信版本、基础库版本、网络类型、构建版本和时间。两台设备执行登录/恢复、初始化或邀请、成员权限、分类/账户、收入/支出、编辑/软删除/冲突、统计月份、网络失败恢复、退出/再次登录。若 Mate 70 Pro 使用 HarmonyOS NEXT 或其他原生鸿蒙系统，单独记录为 HarmonyOS，不自动当作 Android 覆盖。人工结果须有截图、请求编号和版本信息；模拟器、离线测试和 WXML 编译不能代替真机证据。
