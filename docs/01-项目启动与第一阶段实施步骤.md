# 记账本微信小程序：项目启动与第一阶段实施步骤

> 文档版本：V1.0  
> 编制日期：2026-08-13  
> 适用项目：10 人以内微信共享记账小程序  
> 技术方案：微信原生小程序 + Spring Boot + Nginx + MySQL  
> 部署约束：Linux 原生部署，不使用 Docker、Redis、微服务和消息队列

## 1. 本阶段目标

项目开始时不要在“先创建项目”与“先开发小程序页面”之间二选一。

正确做法是：

1. 先确认微信小程序账号、AppID、AppSecret、域名和备案等存在外部等待时间的事项。
2. 当天创建 Spring Boot 后端工程和微信小程序 TypeScript 工程。
3. 开发时先贯通最小纵向链路：

```text
微信小程序 wx.login
        ↓
Spring Boot 接收临时 code
        ↓
微信 code2Session
        ↓
创建用户、默认账本和登录会话
        ↓
MySQL 持久化
        ↓
小程序携带 Token 调用 /me
```

第一阶段不以“首页已经画出来”为完成标准，而以微信登录、后端认证和数据库持久化形成闭环为完成标准。

## 2. 总体实施顺序

```text

```

## 3. 第一步：处理微信小程序账号

### 3.1 注册或确认小程序账号

进入微信公众平台：

- <https://mp.weixin.qq.com/>

确认以下内容：

- [x] 小程序账号已注册并完成主体认证。
- [x] 管理员微信能够登录后台。
- [x] 已取得正式 AppID。
- [x] 已生成并安全保存 AppSecret。
- [x] 已添加开发者成员。
- [x] 已添加体验成员。
- [x] 已确定小程序名称、头像和简介。
- [x] 已确认适用的服务类目。
- [x] 已开始准备隐私保护指引、用户协议和注销说明。

安全要求：

- AppID 可以写入微信小程序工程。
- AppSecret 只能保存在 Spring Boot 服务端。
- AppSecret 不得写入小程序代码。
- AppSecret 不得提交到 Git。
- AppSecret 不得输出到后端日志。
- AppSecret 应保存在密码管理器以及生产 Linux 的受限配置文件中。
- 第一版不申请手机号、位置、通讯录和相册等非必要权限。

微信登录时，小程序调用 `wx.login` 获取临时 code，后端再使用 AppID、AppSecret 和 code 调用 `code2Session`。

官方参考：

- [微信小程序 wx.login](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/login/wx.login.html)
- [微信小程序 code2Session](https://developers.weixin.qq.com/miniprogram/dev/OpenApiDoc/user-login/code2Session.html)

### 3.2 同时启动域名与备案准备

准备独立 API 域名，例如：

```text
api.book.example.com
```

并行处理：

- [x] 域名注册。
- [x] 域名实名认证。
- [x] 按实际情况办理 ICP 备案。
- [x] 配置 DNS 解析。
- [x] 申请可信 HTTPS 证书。
- [x] 在微信公众平台配置 request 合法域名。

不需要等待备案和证书全部完成后才开始本地开发。微信开发者工具在本地调试阶段可以暂时关闭合法域名校验，但正式版必须使用已经配置的 HTTPS 域名。

注意：

- 手机中的 `127.0.0.1` 指向手机自身，不是开发电脑。
- `http://127.0.0.1:8080` 只适合微信开发者工具本地联调。
- 真机联调最终应使用 HTTPS 测试域名或正式域名。
- 正式版不能跳过合法域名和 HTTPS 校验。

官方参考：

- [微信小程序网络通信与合法域名](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)

### 7.1 建库和账号

```powershell

```

执行：

```sql
CREATE DATABASE account_book_dev
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;

CREATE DATABASE account_book_test
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;

  IDENTIFIED BY '替换为本地随机密码';

  TO 'account_book_dev'@'localhost';

  TO 'account_book_dev'@'localhost';

```

本地 Spring Boot 不使用 MySQL root 账号。

### 7.2 设置本地环境变量

在 IntelliJ Spring Boot 启动配置中设置：

```text
DB_URL=jdbc:mysql://localhost:3306/account_book_dev?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
DB_USERNAME=account_book_dev
DB_PASSWORD=你的本地数据库密码
WECHAT_APP_ID=你的小程序AppID
WECHAT_APP_SECRET=你的小程序AppSecret
APP_BOOTSTRAP_KEY=一个至少20位的本地随机字符串
```

不要把密码、AppSecret 或初始化密钥直接写入受 Git 管理的 `application.yml`。

## 10. 打通第一个最小业务链路

### 10.1 后端开发顺序

#### 1. `WechatCode2SessionClient`

职责：

- 接收小程序临时 code。
- 使用 AppID 和 AppSecret 调用微信 `code2Session`。
- 解析 `openid`、`session_key` 和微信错误码。
- 不记录 code、session_key 和 AppSecret。

#### 2. `WechatLoginService`

职责：

- 根据 openid 查询现有用户。
- 未注册用户必须通过首次初始化或有效邀请进入系统。
- 已禁用或已注销用户不能创建新会话。

#### 3. `BootstrapService`

首位用户提交正确 `bootstrapKey` 后，在同一个数据库事务中创建：

- `app_user`。
- 默认 `ledger`。
- OWNER 类型的 `ledger_member`。
- 默认收入分类。
- 默认支出分类。
- 默认“微信”和“现金”资金账户。
- 将 `app_config.initialized` 更新为 `true`。

初始化过程必须对 `app_config` 单例记录加行锁，确保并发请求只能成功一个。

#### 4. `AuthSessionService`

职责：

- 使用 `SecureRandom` 生成 32 字节随机令牌。
- 使用 Base64URL 编码返回给小程序。
- 数据库只保存令牌的 SHA-256 摘要。
- 设置 30 天有效期。
- 退出时撤销当前会话。

#### 5. `BearerTokenAuthenticationFilter`

职责：

- 读取 `Authorization: Bearer <token>`。
- 对原始 Token 计算 SHA-256。
- 查询未撤销、未到期且用户有效的会话。
- 建立 Spring Security 当前用户上下文。

#### 6. 第一批接口

```text
POST /api/v1/auth/wechat-login
POST /api/v1/auth/logout
GET  /api/v1/me
```

登录请求：

```json
{
  "code": "wx.login返回的临时code",
  "inviteCode": null,
  "bootstrapKey": "仅首次管理员初始化时提交"
}
```

### 10.2 小程序开发顺序

1. 调用 `wx.login()`。
2. 将临时 code 发送到 `/api/v1/auth/wechat-login`。
3. 首次初始化页面允许管理员手工输入 `bootstrapKey`。
4. 收到 Token 后使用 `wx.setStorageSync` 保存。
5. 创建统一的 `request.ts`。
6. 每个业务请求自动添加认证头和请求 ID。
7. 调用 `/api/v1/me`。
8. 在临时首页显示当前用户和默认账本。

请求头：

```http
Authorization: Bearer <token>
X-Request-Id: <UUID>
```

注意：

- `bootstrapKey` 不得硬编码到小程序源代码。
- 首位管理员只能在初始化页手工输入一次。
- 初始化成功后应从生产服务器环境文件删除 `APP_BOOTSTRAP_KEY` 并重启服务。
- 遇到 401 时最多自动重新登录一次，防止请求刷新死循环。

## 11. 第一阶段验收标准

在以下项目全部通过前，不进入完整账单页面开发：

- [ ] 微信开发者工具能够取得 `wx.login` code。
- [ ] Spring Boot 能够调用微信 `code2Session`。
- [ ] AppSecret 未出现在小程序、Git 和日志中。
- [ ] 错误初始化密钥不能创建用户。
- [ ] 正确初始化后只创建一个首位用户。
- [ ] 自动创建一个默认账本。
- [ ] 首位用户角色为 OWNER。
- [ ] 自动创建默认收入分类、支出分类和资金账户。
- [ ] `auth_session` 只保存 Token 摘要。
- [ ] 携带有效 Token 调用 `/api/v1/me` 成功。
- [ ] 不携带 Token 返回 HTTP 401。
- [ ] 携带错误或已撤销 Token 返回 HTTP 401。
- [ ] 第二次登录不会重复创建用户和默认账本。
- [ ] 退出后原 Token 立即失效。

数据库核对 SQL：

```sql
SELECT id, nickname, status
FROM app_user;

SELECT id, name, owner_user_id, status
FROM ledger;

SELECT ledger_id, user_id, role, status
FROM ledger_member;

SELECT id, user_id, token_hash, expires_at, revoked_at
FROM auth_session;
```
