## 2. 数据库脚本职责

### 2.1 管理员初始化脚本

文件：

```text
deploy/mysql/00-create-database-and-user.sql
```

用途：

- 创建 `account_book` 数据库。
- 设置数据库默认字符集为 `utf8mb4`。
- 设置数据库默认排序规则为 `utf8mb4_0900_ai_ci`。
- 创建仅允许从 `127.0.0.1` 登录的 `account_book_app` 用户。
- 由 MySQL 生成随机密码，不在 Git 中写入固定密码。
- 设置单个应用账号最多 20 个并发连接。
- 授予该账号 `account_book.*` 库级权限，供 Flyway 和应用使用。
- 输出数据库、账号和授权验证结果。

### 2.2 Flyway V1

文件：

```text
account-book-server/src/main/resources/db/migration/V1__init_schema.sql
```

用途：由 Spring Boot 启动时的 Flyway 自动创建：

1. `app_config`
2. `app_user`
3. `auth_session`
4. `ledger`
5. `ledger_member`
6. `ledger_invite`
7. `category`
8. `fund_account`
9. `book_entry`
10. `audit_log`

不要用 root 手工执行 V1，也不要在 V1 成功执行后修改它。后续结构变更只能新增 `V2__...sql`、`V3__...sql`。

## 3. 第一步：把管理员初始化 SQL 上传到服务器

在 Windows PowerShell 执行，替换服务器地址和登录账号：

```powershell
$ProjectRoot = "D:\Work\Workplaces\privateWork\AAProject\MyTallyBook_Project"
$Server = "deploy@替换为京东云公网IP"

scp `
  "$ProjectRoot\deploy\mysql\00-create-database-and-user.sql" `
  "${Server}:/tmp/00-create-database-and-user.sql"
```

登录服务器：

```powershell
ssh $Server
```

## 4. 第二步：执行数据库和账号初始化

进入 root shell：

```bash
sudo -i
```

先检查 MySQL：

```bash
systemctl is-active mysql
mysql --protocol=socket --table -e "
SELECT VERSION() AS mysql_version,
       @@GLOBAL.character_set_server AS character_set_server,
       @@GLOBAL.collation_server AS collation_server,
       @@GLOBAL.lower_case_table_names AS lower_case_table_names;
"
```

预期：

```text
mysql_version           8.4.x
character_set_server    utf8mb4
collation_server        utf8mb4_0900_ai_ci
lower_case_table_names  1
```

检查应用账号是否已经存在：

```bash
mysql --protocol=socket --batch --skip-column-names -e "
SELECT COUNT(*)
FROM mysql.user
WHERE user='account_book_app' AND host='127.0.0.1';
"
```

结果必须为 `0`。如果结果是 `1`，不要直接重跑创建脚本，因为旧账号密码不会再次显示；先核对该账号是否来自当前项目。

执行初始化，并把随机密码输出保存到仅 root 可读文件：

```bash
set -o pipefail
umask 077

DB_BOOTSTRAP_OUTPUT="/root/account-book-db-bootstrap-$(date +%Y%m%d_%H%M%S).txt"

if ! mysql --protocol=socket --table \
  < /tmp/00-create-database-and-user.sql \
  | tee "${DB_BOOTSTRAP_OUTPUT}"; then
  echo 'ERROR: 数据库初始化失败。'
  exit 1
fi

chmod 600 "${DB_BOOTSTRAP_OUTPUT}"
echo "随机密码和验证结果保存在：${DB_BOOTSTRAP_OUTPUT}"
```

`CREATE USER ... IDENTIFIED BY RANDOM PASSWORD` 会在结果集中显示一次明文随机密码。立即将它保存到密码管理器；不要截图、发送到聊天工具或提交到 Git。

如果 MySQL root 使用密码认证，把上面命令中的：

```bash
mysql --protocol=socket
```

改成：

```bash
mysql -uroot -p
```

## 5. 第三步：验证应用账号

从刚才的 root 文件中读取生成结果：

```bash
less "${DB_BOOTSTRAP_OUTPUT}"
```

使用结果中的随机密码测试 TCP 登录：

```bash
mysql -h127.0.0.1 -P3306 -uaccount_book_app -p \
  -e "SELECT CURRENT_USER() AS current_user, DATABASE() AS current_database;" \
  account_book
```

检查数据库默认字符集：

```bash
mysql -h127.0.0.1 -P3306 -uaccount_book_app -p --table -e "
SELECT SCHEMA_NAME,
       DEFAULT_CHARACTER_SET_NAME,
       DEFAULT_COLLATION_NAME
FROM information_schema.SCHEMATA
WHERE SCHEMA_NAME='account_book';
"
```

预期：

```text
account_book  utf8mb4  utf8mb4_0900_ai_ci
```

## 6. 第四步：本地 IDEA 通过 SSH 隧道访问数据库

不要在京东云安全组中向公网开放 3306。

在 Windows 新开一个 PowerShell 窗口并保持运行：

```powershell
ssh -N -L 13306:127.0.0.1:3306 deploy@替换为京东云公网IP
```

本地 Spring Boot 使用：

```text
DB_URL=jdbc:mysql://127.0.0.1:13306/account_book?useUnicode=true&characterEncoding=UTF-8&connectionTimeZone=Asia%2FShanghai
DB_USERNAME=account_book_app
DB_PASSWORD=替换为MySQL生成的随机密码
```

在 IntelliJ IDEA 中设置位置：

```text
Run -> Edit Configurations -> account-book-server -> Environment variables
```

数据库密码只放在 IDEA 本地运行配置或 Linux 受限环境文件，不写入 `application.yml`。

## 7. 第五步：补齐 Spring Boot 数据库配置

下一开发任务创建：

```text
account-book-server/src/main/resources/application.yml
account-book-server/src/main/resources/application-dev.yml
account-book-server/src/main/resources/application-prod.yml
```

必须配置：

```yaml
spring:
  datasource:
    url: ${DB_URL}
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
    hikari:
      maximum-pool-size: 10
      minimum-idle: 2
  jpa:
    open-in-view: false
    hibernate:
      ddl-auto: validate
  flyway:
    enabled: true
```

禁止使用：

```yaml
spring:
  jpa:
    hibernate:
      ddl-auto: update
```

## 8. 第六步：首次运行 Flyway

确认 SSH 隧道仍然运行，然后在项目 PowerShell 中执行：

```powershell
Set-Location -LiteralPath "D:\Work\Workplaces\privateWork\AAProject\MyTallyBook_Project\account-book-server"

$env:DB_URL = "jdbc:mysql://127.0.0.1:13306/account_book?useUnicode=true&characterEncoding=UTF-8&connectionTimeZone=Asia%2FShanghai"
$env:DB_USERNAME = "account_book_app"
$env:DB_PASSWORD = "替换为MySQL生成的随机密码"

.\mvnw.cmd spring-boot:run "-Dspring-boot.run.profiles=dev"
```

启动成功后，Flyway 应执行 `V1__init_schema.sql`。

## 9. 第七步：验证 Flyway 和表结构

在服务器或本地 SSH 隧道上执行：

```sql
SELECT installed_rank,
       version,
       description,
       type,
       script,
       success
FROM flyway_schema_history
ORDER BY installed_rank;

SELECT table_name
FROM information_schema.tables
WHERE table_schema='account_book'
ORDER BY table_name;

SELECT id, initialized, max_users, version
FROM app_config;
```

预期：

- Flyway V1 的 `success=1`。
- 10 张业务表全部存在。
- 额外存在 `flyway_schema_history`。
- `app_config` 有一条 `id=1`、`initialized=0`、`max_users=10` 的记录。

## 10. 下一阶段计划

### 阶段 A：数据库连接闭环

1. 创建 `application-dev.yml` 和 `application-prod.yml`。
2. 配置 Hikari、JPA validate、Flyway 和 Actuator。
3. 本地通过 SSH 隧道连接京东云 MySQL。
4. 首次启动并验证 V1。
5. 补充数据库启动失败和 Flyway 失败的自动化测试。

完成标准：应用能够启动，`/actuator/health` 返回 `UP`，Flyway V1 成功。

### 阶段 B：后端公共基础

1. 统一 API 响应和错误码。
2. 全局异常处理。
3. 请求 ID 和结构化日志。
4. Spring Security 默认拒绝规则。
5. 令牌摘要、时间和安全随机数工具。
6. `app_config`、`app_user`、`auth_session` 的 JPA 实体和 Repository。

完成标准：匿名只能访问健康检查和微信登录接口，其他接口返回 401。

### 阶段 C：微信登录最小闭环

1. 实现微信 `code2Session` 客户端。
2. 实现首位管理员 `bootstrapKey` 初始化。
3. 在同一事务创建首位用户、默认账本和 OWNER 成员。
4. 创建默认分类和资金账户。
5. 生成应用会话令牌，数据库只保存 SHA-256 摘要。
6. 实现 `/api/v1/auth/wechat-login`、`/api/v1/auth/logout`、`/api/v1/me`。

完成标准：同一个微信用户重复登录不会重复创建用户和默认账本。

### 阶段 D：创建微信原生小程序

只有阶段 C 的后端接口通过测试后再创建：

```text
account-book-miniapp/
```

第一批只实现：

1. `wx.login`。
2. 登录接口调用。
3. 安全保存应用令牌。
4. 获取并显示当前用户和默认账本。
5. 401 后清理令牌并重新登录。

完成标准：开发者工具和真机都能完成微信登录最小闭环。

9. 最后创建微信小程序工程。
