# 小程序目录与文件职责

本文以 `account-book-miniapp/` 的常规源码清单为准：盘点时 `rg --files` 列出 **163** 个源码、配置、测试和声明文件，`miniprogram/pages` 有 **20** 个实际页面。该计数不包含被 `.gitignore` 排除的本机私有配置，也不包含隐藏占位文件；因此它不是“全部受版本管理文件”的断言。链接从本文所在的 `docs/目录说明/` 目录计算。

## 目录树与功能定位

```text
../../account-book-miniapp/
├─ miniprogram/                         # 微信小程序运行时根目录（project.config.json 指向此处）
│  ├─ app.ts                            # 小程序入口；目前仅初始化 globalData
│  ├─ app.json                          # 注册 20 页、窗口样式及四个自定义 Tab
│  ├─ app.wxss                          # 全局颜色、排版、卡片、按钮等公共样式
│  ├─ runtime.ts                        # 组装环境、HTTP、会话、流程和 API 的单例运行时
│  ├─ config/                           # API 运行环境与产品公开信息
│  ├─ custom-tab-bar/                   # 首页／明细／统计／我的四 Tab 组件
│  ├─ flows/                            # 面向页面的业务编排层
│  ├─ pages/                            # 20 个已注册页面；每页由 TS、WXML、WXSS、JSON 构成
│  ├─ services/                         # 后端 HTTP API 与微信登录适配层
│  ├─ store/                            # 本地会话状态及持久化
│  ├─ types/                            # API、账本、账单、统计和错误的 TypeScript 契约
│  └─ utils/                            # 校验、记账草稿、导航、页面异步防护与展示转换
├─ tests/                               # Vitest 单元、接口契约和页面流程测试
├─ typings/                             # 微信小程序全局 TypeScript 声明及本地副本
├─ package.json                         # Node 版本、依赖与 test/typecheck 脚本
├─ package-lock.json                    # npm 依赖锁定文件
├─ project.config.json                  # 微信开发者工具工程、编译与上传设置
├─ project.private.config.json           # 被 gitignore 排除的本机开发者工具覆盖设置
├─ .gitkeep                             # 隐藏的项目根目录版本控制占位
├─ tsconfig.json                        # 小程序生产源码的严格类型检查配置
├─ tsconfig.test.json                   # 测试与 Vitest 配置文件的类型检查扩展配置
└─ vitest.config.mts                    # Vitest Node 环境、测试文件匹配与 mock 恢复规则
```

`node_modules/` 是 npm 安装的第三方依赖，`miniprogram_npm/`（如开发者工具生成）是小程序 npm 构建产物，`dist/`、`coverage/` 等构建／覆盖率缓存均不记录内部明细，也不是本功能源码。

## 页面：路由、四文件分工与特有职责

所有实际页面位于 [`../../account-book-miniapp/miniprogram/pages/`](../../account-book-miniapp/miniprogram/pages/)。每页均有相同的文件职责：`index.ts` 管理 `Page` 生命周期、状态、事件和流程调用；`index.wxml` 定义数据绑定后的页面结构；`index.wxss` 定义该页局部视觉样式；`index.json` 定义页面级导航栏和组件配置。以下为每页在此共性之外的职责。

## 配置、运行时与公共模块

### `miniprogram/config/`

- [`env.ts`](../../account-book-miniapp/miniprogram/config/env.ts)：根据微信 `develop`、`trial`、`release` 环境解析 API 地址、10 秒超时，并校验体验版／正式版只能使用合法 HTTPS 域名。开发环境固定使用 `http://127.0.0.1:7631`；`trial` 和 `release` 分别读取各自部署域名（当前两者均为 `https://www.cr-chenny.com`）。
- [`app-info.ts`](../../account-book-miniapp/miniprogram/config/app-info.ts)：应用名称、版本、运营方、联系信息与备案查询展示数据。

### `miniprogram/runtime.ts` 与 `store/`

- [`runtime.ts`](../../account-book-miniapp/miniprogram/runtime.ts)：创建环境隔离的会话存储、HTTP 客户端、全部 API 与 `SessionFlow`／业务 Flow；收到当前令牌的 401 会清会话并重启到登录页。
- [`store/session.ts`](../../account-book-miniapp/miniprogram/store/session.ts)：以 `mytallybook.session.v1` 持久化有效令牌、过期时间和环境标识；内存保存用户／账本上下文及 revision，用于取消过期异步操作。

### `miniprogram/services/`

- [`http.ts`](../../account-book-miniapp/miniprogram/services/http.ts)：请求 ID、Authorization、响应信封解析、HTTP／网络／超时错误标准化、单次未授权回调及 `wx.request` 执行器。
- [`wechat.ts`](../../account-book-miniapp/miniprogram/services/wechat.ts)：封装 `wx.login`，取得微信 code 并转为统一 `AppError`。
- [`auth.ts`](../../account-book-miniapp/miniprogram/services/auth.ts)：微信登录、首次初始化、登出 API。
- [`user.ts`](../../account-book-miniapp/miniprogram/services/user.ts)：读取当前用户与更新昵称 API。
- [`ledger.ts`](../../account-book-miniapp/miniprogram/services/ledger.ts)：读取固定共享账本 API。
- [`invite.ts`](../../account-book-miniapp/miniprogram/services/invite.ts)：创建、分页筛选、撤销、接受邀请 API，并校验有效期／分页／token 关联参数。
- [`member.ts`](../../account-book-miniapp/miniprogram/services/member.ts)：成员列表、角色变更、移除、所有权转让 API，以及安全 ID 校验。
- [`catalog.ts`](../../account-book-miniapp/miniprogram/services/catalog.ts)：分类、账户的列表、详情、新建、更新、删除 API；校验 ID、版本与查询参数。
- [`entry.ts`](../../account-book-miniapp/miniprogram/services/entry.ts)：账单列表、详情、创建人选项、新建、更新、删除 API；处理筛选、分页和版本校验。
- [`statistics.ts`](../../account-book-miniapp/miniprogram/services/statistics.ts)：月汇总、日趋势、分类／账户／成员排行 API；互斥校验月、全部范围或日期区间。

### `miniprogram/flows/`

- [`session-flow.ts`](../../account-book-miniapp/miniprogram/flows/session-flow.ts)：会话恢复／微信登录的入口分流（首页、初始化、待邀请），刷新用户与账本上下文，初始化、昵称更新、登出及身份代际防护。
- [`invite-flow.ts`](../../account-book-miniapp/miniprogram/flows/invite-flow.ts)：创建／撤销邀请后刷新上下文；接受邀请时校验 43 位 token、登录并建立会话。
- [`member-flow.ts`](../../account-book-miniapp/miniprogram/flows/member-flow.ts)：成员管理后刷新上下文；本人被移除时清本地会话。
- [`catalog-flow.ts`](../../account-book-miniapp/miniprogram/flows/catalog-flow.ts)：分类、账户 API 的页面友好转发层。
- [`entry-flow.ts`](../../account-book-miniapp/miniprogram/flows/entry-flow.ts)：账单 API 转发、客户端请求 UUID，以及避免重复创建／支持不确定结果原请求重试的 `EntryCreateIntent`。
- [`statistics-flow.ts`](../../account-book-miniapp/miniprogram/flows/statistics-flow.ts)：统计 API 的聚合转发层。

### `miniprogram/types/`

- [`api.ts`](../../account-book-miniapp/miniprogram/types/api.ts)：通用 API 成功／错误信封，认证状态，用户、账本、邀请、成员角色与分页契约。
- [`catalog.ts`](../../account-book-miniapp/miniprogram/types/catalog.ts)：分类、账户、状态、收支类型、账户类型以及创建／更新载荷。
- [`entry.ts`](../../account-book-miniapp/miniprogram/types/entry.ts)：账单、创建人、分页、筛选、新建和更新账单契约。
- [`statistics.ts`](../../account-book-miniapp/miniprogram/types/statistics.ts)：统计范围、周期元数据、汇总、趋势及各类排行契约。
- [`error.ts`](../../account-book-miniapp/miniprogram/types/error.ts)：统一 `AppError` 类型、错误种类、代码、请求 ID 和 HTTP 状态。

### `miniprogram/utils/` 与 `custom-tab-bar/`

- [`utils/validation.ts`](../../account-book-miniapp/miniprogram/utils/validation.ts)：初始化口令、昵称的长度与去空白校验。
- [`utils/bookkeeping.ts`](../../account-book-miniapp/miniprogram/utils/bookkeeping.ts)：上海日期、账单 ID 与金额／日期／字段限制校验，并生成新增账单草稿。
- [`utils/navigation.ts`](../../account-book-miniapp/miniprogram/utils/navigation.ts)：四个 Tab 路由常量；Tab 使用 `switchTab`，其他页使用 `navigateTo`。
- [`utils/page-guard.ts`](../../account-book-miniapp/miniprogram/utils/page-guard.ts)：以页面存活、页面 generation 与会话 revision 拒绝已失效异步回调。
- [`utils/presentation.ts`](../../account-book-miniapp/miniprogram/utils/presentation.ts)：将异常转换为页面文案／请求号，以及成员角色中文标签。
- [`custom-tab-bar/index.ts`](../../account-book-miniapp/miniprogram/custom-tab-bar/index.ts)：基于当前页面同步选中态、切换四个 Tab；[`index.wxml`](../../account-book-miniapp/miniprogram/custom-tab-bar/index.wxml) 渲染可访问 Tab 列表；[`index.wxss`](../../account-book-miniapp/miniprogram/custom-tab-bar/index.wxss) 固定底部和安全区样式；[`index.json`](../../account-book-miniapp/miniprogram/custom-tab-bar/index.json) 声明组件。

## 根配置、测试与 typings

### 根文件

- [`package.json`](../../account-book-miniapp/package.json) 与 [`package-lock.json`](../../account-book-miniapp/package-lock.json)：锁定 Node `>=24.20.0 <25`、npm 11.19.0、TypeScript、Vitest 和微信类型依赖；暴露 `test`、`test:watch`、`typecheck`。
- [`project.config.json`](../../account-book-miniapp/project.config.json)：微信开发者工具工程根、TypeScript 编译、模拟器、上传压缩和 source map 等设置。
- `project.private.config.json`：本机微信开发者工具私有设置；其中同名字段覆盖 `project.config.json`，当前包括热重载、域名校验等调试偏好和本机基础库版本。该文件被 `.gitignore` 排除，故不纳入 163 文件的常规清单。
- [`.gitkeep`](../../account-book-miniapp/.gitkeep)：隐藏占位文件，用于保留项目根目录的版本控制占位；不参与小程序运行，也未纳入 163 文件的常规清单。
- [`tsconfig.json`](../../account-book-miniapp/tsconfig.json)：严格检查 `miniprogram/**/*.ts` 和入口声明，排除测试及 vendored typings。
- [`tsconfig.test.json`](../../account-book-miniapp/tsconfig.test.json)：为测试开启 ESNext／Bundler 解析和 Node 类型。
- [`vitest.config.mts`](../../account-book-miniapp/vitest.config.mts)：Node 测试环境，匹配 `tests/**/*.{test,spec}.ts`，每例清理／恢复 mock。
