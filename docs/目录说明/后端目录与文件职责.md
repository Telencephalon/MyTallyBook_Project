# 后端目录与文件职责

本文按当前工作区实际清单整理 `account-book-server`。统计口径：生产 Java 95 个、测试 Java 54 个、配置 3 个、Flyway 迁移 4 个（2026-09-20 核对）。链接均从本文件所在的 `docs/目录说明/` 计算。

## 根目录、构建与产物

| 文件或目录 | 职责 |
| --- | --- |
| [`account-book-server/`](../../account-book-server/) | Spring Boot 4 / Java 21 后端模块；提供小程序 API、MySQL 持久化及 Flyway 建表演进。 |
| [`pom.xml`](../../account-book-server/pom.xml) | Maven 坐标与 Spring Boot 4.1.0 父 POM；引入 WebMVC、Security、Validation、JPA、Flyway/MySQL、Actuator 及对应测试 starter，`spring-boot-maven-plugin` 打包可执行 jar。 |
| [`mvnw`](../../account-book-server/mvnw)、[`mvnw.cmd`](../../account-book-server/mvnw.cmd) | Unix/Windows Maven Wrapper 启动脚本，使用项目锁定的 Wrapper 下载/调用 Maven。 |
| [`.mvn/`](../../account-book-server/.mvn/) | Maven Wrapper 配置目录；当前 [`wrapper/maven-wrapper.properties`](../../account-book-server/.mvn/wrapper/maven-wrapper.properties) 指定 Maven 3.9.16 的下载地址和 `only-script` 模式，目录内**没有** `maven-wrapper.jar`。 |
| [`.gitignore`](../../account-book-server/.gitignore)、[`.gitattributes`](../../account-book-server/.gitattributes) | Git 忽略规则与文本属性。 |
| [`HELP.md`](../../account-book-server/HELP.md) | Spring Initializr 生成的构建/依赖帮助说明。 |
| [`target/`](../../account-book-server/target/) | 本地 Maven 构建缓存与产物，不是业务源码：`classes/`、`test-classes/` 为编译结果，`generated-*-sources/` 为生成源码位置，`maven-status/` 为增量编译状态，`surefire-reports/` 为测试报告，`maven-archiver/` 为 jar 元数据；`account-book-server-0.0.1-SNAPSHOT.jar` 是打包结果，`.jar.original` 是重打包前原 jar。现有 `manual-check-*`、`server-upload-*`、`*.log`、`favor-tabs-wxml.js` 也是本地检查/上传留存，不能当作可发布源文件。 |

│   │   │   ├── ledger/                        # 固定账本读取和读写不变量/锁
│   │   │   ├── member/                        # 成员、角色、退出、转让与 store/
│   │   │   │   └── store/                     # ledger_member JDBC 持久化契约/实现
│   │   │   ├── security/                      # Bearer 验证、Security 链、401/403
│   │   │   ├── statistics/                    # 汇总、趋势、排行、统计周期与 store/
│   │   │   │   └── store/                     # 账目聚合 JDBC 契约/实现
│   │   │   └── user/                          # 当前用户资料读取/更新
│   │   └── resources/

`7631` 是本服务的 HTTP **监听端口**；`3306` 是 MySQL 常用的数据库**连接端口**，通常只会包含在 `DB_URL` 中。两者服务对象和网络层不同，配置文件没有把 3306 写死。

### Flyway 迁移和表功能对照

| 迁移 | 实际 SQL 变更 | 涉及表及功能 |
| --- | --- | --- |
| [`V1__init_schema.sql`](../../account-book-server/src/main/resources/db/migration/V1__init_schema.sql) | 建立初始 10 张表及索引、外键、CHECK 约束；插入唯一 `app_config(id=1)`。 | `app_config`：初始化/全局人数上限；`app_user`：微信用户；`auth_session`：哈希会话；`ledger`：账本；`ledger_member`：账本成员与角色；`ledger_invite`：多次使用计数式邀请（后由 V2 替换）；`category`：收支分类；`fund_account`：现金/微信/银行卡/支付宝等资金账户；`book_entry`：收支账目（含旧 `member_id`）；`audit_log`：操作审计。 |
| [`V2__align_approved_design.sql`](../../account-book-server/src/main/resources/db/migration/V2__align_approved_design.sql) | 先临时表断言旧数据可安全演进；为 `ledger` 加常量唯一键/单例约束；把邀请改为 `used_by/used_at` 单次消费状态；删除 `book_entry.member_id`，改建 `created_by` 索引；审计 `request_id` 从 `CHAR(36)` 扩展为 ASCII `VARCHAR(64)`。 | 强化唯一固定账本设计；`ledger_invite` 支持 ACTIVE/USED/REVOKED/EXPIRED 和消费人；`book_entry` 以创建人为统计维度；`audit_log` 支持受控长度请求 ID。 |
| [`V3__add_entry_person_name.sql`](../../account-book-server/src/main/resources/db/migration/V3__add_entry_person_name.sql) | 在 `book_entry.note` 后新增可空 `person_name VARCHAR(64)`。 | 人情往来人名字段；由账目创建/更新、查询和统计历史账目共用。 |
| [`V4__allow_shared_category_type.sql`](../../account-book-server/src/main/resources/db/migration/V4__allow_shared_category_type.sql) | 删除旧分类类型 CHECK，重建为 INCOME、EXPENSE、BOTH。 | `category.entry_type=BOTH` 可供收入和支出共同使用；账目服务据此验证匹配。 |
