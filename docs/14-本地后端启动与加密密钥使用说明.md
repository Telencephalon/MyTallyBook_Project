## 2. 密钥与密码的区别

| 值 | 来源 | 本次保存方式 |
|---|---|---|
| APP_BOOTSTRAP_KEY | 首次自动生成，用于开发库唯一所有者初始化 | 当前 Windows 用户 DPAPI 加密保存 |

| WECHAT_APP_SECRET | 微信公众平台同一 AppID 对应的 AppSecret | 同上；AppID 仍来自项目配置，私有配置绑定同一 AppID |

密钥文件固定为 `secrets/local-dev/keys.dpapi`，不包含数据库密码或 AppSecret，不保存明文初始化口令或 Pepper。用户在 2026-09-05 另行确认将 AppSecret 和开发库密码加密保存于独立的 `secrets/local-dev/credentials.dpapi`，旧密钥文件保持不变；AppID 继续保留在小程序 `project.config.json` 中。两份私有文件均不进入 Git 或 JAR。启动命令不输出生成的密钥，也不自动复制到剪贴板。项目所有者另行批准的查看命令仅在本人本地终端显示初始化口令，用于小程序首次初始化；Pepper 始终不显示。该授权不包含自动创建所有者或修改数据库。

DPAPI 的 CurrentUser 模式使用 Windows 用户配置保护数据，不能把该密文直接当作 Linux 生产配置使用；Windows 重装、账户/profile 变更可能影响解密。它也不能阻止已获得同一账户权限的程序读取运行中的进程。参考 [Microsoft ProtectedData 文档](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.protecteddata?view=windowsdesktop-9.0)。

不要删除文件来“重新生成密码”。已存在文件只能读取复用；损坏、无法解密或格式异常时停止，不覆盖、不轮换。Pepper 变化会使旧会话无法认证。仅复制该密文不是可跨机器恢复的完整密钥备份；生产密钥管理留到部署阶段单独处理。

文件损坏、AppID 不匹配或 ACL 异常时停止，不静默重建、不覆盖、不重新询问密码。若首次输入错误，需要单独确认后受控更新凭据；不要删除或改写 `keys.dpapi`，也不要把加密文件当作文本 YAML/JSON 编辑。当前没有自动更新/轮换命令。
