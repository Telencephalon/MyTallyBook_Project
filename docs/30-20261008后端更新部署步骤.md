## 2. 服务器校验并记录旧版本

## 3. 安装并重启

使用 `--no-restart` 将安装与健康等待分开。`--keep` 取现有 JAR 数量加一，保留全部版本；不会覆盖同名发布包。沿用服务器已有 env、service、Nginx、证书和数据库配置。

```bash
(
set -euo pipefail
test "$(id -u)" -eq 0
cd /root/server-upload-20261008-101349
RECORD='/root/account-book-release-record-20261008-101349'
test -s "$RECORD/previous-jar-path.txt"
sha256sum -c "$RECORD/previous-jar.sha256"
test "$(readlink -f /opt/account-book/current.jar)" = \
  "$(cat "$RECORD/previous-jar-path.txt")"
sha256sum -c SHA256SUMS
test ! -e /opt/account-book/releases/account-book-server-20261008-101349.jar
KEEP_COUNT=$(( $(find /opt/account-book/releases -maxdepth 1 -type f -name '*.jar' | wc -l) + 1 ))
bash ./install-release.sh \
  --artifact ./account-book-server-20261008-101349.jar \
  --sha256 ./SHA256SUMS --keep "$KEEP_COUNT" --no-restart
test "$(readlink -f /opt/account-book/current.jar)" = \
  '/opt/account-book/releases/account-book-server-20261008-101349.jar'
runuser -u accountbook -- test -r /opt/account-book/current.jar
systemctl restart account-book.service
READY=0
DEADLINE=$((SECONDS + 120))
while (( SECONDS < DEADLINE )); do
  if HEALTH=$(curl -fsS --connect-timeout 2 --max-time 3 \
      http://127.0.0.1:7631/actuator/health 2>/dev/null); then
    if printf '%s' "$HEALTH" | grep -Eq '^\{[[:space:]]*"status"[[:space:]]*:[[:space:]]*"UP"[[:space:]]*\}[[:space:]]*$'; then
      READY=1
      break
    fi
  fi
  sleep 2
done
if [ "$READY" -ne 1 ]; then
  echo '新版在等待期内未就绪，请执行下方回退步骤。' >&2
  journalctl -u account-book.service -n 60 --no-pager
  exit 1
fi
readlink -f /opt/account-book/current.jar
sha256sum /opt/account-book/current.jar
systemctl is-active account-book.service
printf '%s\n' "$HEALTH"
)
```

## 启动失败时回退到更新前版本

使用第 2 步记录的真实旧版本，不假设服务器仍运行某个历史版本。先校验旧 JAR，再原子切换链接；清除 systemd 启动失败限流后重启，并等待健康状态。保留本次新包用于排查。

```bash
(
set -euo pipefail
test "$(id -u)" -eq 0
RECORD='/root/account-book-release-record-20261008-101349'
OLD=$(cat "$RECORD/previous-jar-path.txt")
case "$OLD" in
  /opt/account-book/releases/*.jar) ;;
  *) echo '旧版本记录路径无效。' >&2; exit 1 ;;
esac
test -f "$OLD"
sha256sum -c "$RECORD/previous-jar.sha256"
runuser -u accountbook -- test -r "$OLD"
test -L /opt/account-book/current.jar
NEXT="/opt/account-book/.current.jar.rollback.$$"
test ! -e "$NEXT"
test ! -L "$NEXT"
ln -s -- "$OLD" "$NEXT"
mv -fT -- "$NEXT" /opt/account-book/current.jar
systemctl reset-failed account-book.service
systemctl restart account-book.service
READY=0
DEADLINE=$((SECONDS + 120))
while (( SECONDS < DEADLINE )); do
  if HEALTH=$(curl -fsS --connect-timeout 2 --max-time 3 \
      http://127.0.0.1:7631/actuator/health 2>/dev/null); then
    if printf '%s' "$HEALTH" | grep -Eq '^\{[[:space:]]*"status"[[:space:]]*:[[:space:]]*"UP"[[:space:]]*\}[[:space:]]*$'; then
      READY=1
      break
    fi
  fi
  sleep 2
done
if [ "$READY" -ne 1 ]; then
  echo '已切回旧 JAR，但服务仍未就绪，请查看日志。' >&2
  journalctl -u account-book.service -n 60 --no-pager
  exit 1
fi
readlink -f /opt/account-book/current.jar
sha256sum /opt/account-book/current.jar
systemctl is-active account-book.service
printf '%s\n' "$HEALTH"
)
```

回退后恢复旧版本的业务行为。这里不恢复或覆盖数据库，也不执行 Flyway clean/repair。
