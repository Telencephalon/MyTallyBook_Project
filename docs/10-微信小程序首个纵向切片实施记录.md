## 1. 本次交付范围

本次完成微信原生 TypeScript 小程序的首个纵向切片：微信登录适配、会话恢复、唯一所有者初始化、固定账本首页、昵称资料维护和退出登录。邀请、成员管理、账单、分类、资金账户和统计仍属于后续任务。

## 2. 实现结构

| 文件组 | 责任 |
|---|---|
| `miniprogram/config/env.ts` | 按 `envVersion` 选择受限 API 地址，阻止体验版和正式版回退到公网 IP 或 HTTP |
| `miniprogram/types/` | 统一 API、认证状态、用户、账本和客户端错误类型 |
| `miniprogram/store/session.ts` | 版本化 Token 持久化和用户/账本内存上下文 |
| `miniprogram/services/http.ts` | 请求 ID、Bearer 头、超时、统一响应解析和 401 单次失效处理 |
| `miniprogram/services/wechat.ts` | 将 `wx.login` 转换为 Promise，并规范化微信能力失败 |
| `miniprogram/services/auth.ts` | 登录、所有者初始化和退出接口 |
| `miniprogram/services/user.ts` | 当前用户查询和昵称更新；小程序使用微信原生请求支持的 `PUT` |
| `miniprogram/services/ledger.ts` | 固定共享账本查询 |
| `miniprogram/flows/session-flow.ts` | 会话启动、初始化、上下文刷新、昵称更新和退出编排 |
| `miniprogram/pages/login/` | 会话恢复、登录、等待邀请和安全错误状态 |
| `miniprogram/pages/bootstrap/` | 一次性初始化口令输入与提交；离开页面时清空口令 |
| `miniprogram/pages/home/` | 只展示真实账本和成员身份数据，不伪造余额或统计 |
| `miniprogram/pages/profile/` | 只读身份信息与昵称修改 |
| `tests/` | 环境、会话、HTTP、API、微信适配、流程、校验、展示与路由测试 |

为兼容 `wx.request` 的方法类型限制，后端本地代码在同一个资料更新控制器方法上同时接受原有 `PATCH` 和新增 `PUT`；校验、服务、审计与响应合同没有复制或分叉。

## 3. 关键行为

1. 启动时优先恢复未过期会话并重新加载用户和账本；没有有效会话时才获取新的微信 code。
2. 登录结果为 `NEED_BOOTSTRAP` 时进入初始化页，`INVITE_REQUIRED` 时停留并提示联系所有者或管理员。
3. 每次提交初始化口令都重新获取微信 code；初始化口令不进入 Storage 或日志。
4. 认证请求自动带请求 ID；需要身份的请求自动带 Bearer 头，但代码不打印头值。
5. 并发 401 只触发一次本地清理和登录页跳转。
6. 昵称提交前去除首尾空白并校验 1～64 个字符；标准化后未变化时不调用后端。
7. 退出成功或服务端返回 401 时清除会话；网络失败或 5xx 时保留会话并允许重试。

## 4. API 环境策略

| 小程序环境 | 当前行为 |
|---|---|
| `develop` | 只请求 `http://127.0.0.1:7631`，用于微信开发者工具本地联调 |
| `trial` | HTTPS API 域名为空时抛出 `API_DOMAIN_NOT_CONFIGURED`，不发送网络请求 |
| `release` | HTTPS API 域名为空时抛出 `API_DOMAIN_NOT_CONFIGURED`，不发送网络请求 |

体验版和正式版明确拒绝 HTTP、`localhost` 和公网 IP。域名完成 ICP 备案、证书和微信后台合法域名配置后，必须显式填写 HTTPS API 域名并重新验证；不能把后端内部端口 `7631` 暴露给小程序。

## 5. 本机会话与敏感信息边界

Storage Key 固定为 `mytallybook.session.v1`，对象只包含以下非秘密字段名：

```text
version
token
expiresAt
```

这里记录的是字段名称，不是任何真实值。用户、角色和账本上下文只保存在运行内存中，重新启动后从服务端加载。

源码与文档不包含 AppSecret、数据库凭据、初始化口令、原始 Token、微信 code、openid、`session_key` 或 Authorization 值。
